# Gesundheit

Private Web-App (PWA) für Eriks Whoop-Daten, Tagesempfehlung und Tagebuch.
Statische Dateien, gehostet über GitHub Pages. Daten liegen ausschließlich in Supabase
(Lesen nur für Eriks Konto per Row Level Security) – im Repo sind keine Gesundheitsdaten.

Installation auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
